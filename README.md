# Realo Kids public site

Static landing site for `realokids.com`, ready for Cloudflare Pages.

## Replace before launch

- Update `playStoreUrl` in `config.js`.
- Add the three app screenshots at the site root:
  - `AppScreenshot1.png`
  - `AppScreenshot2.png`
  - `AppScreenshot3.png`

## Cloudflare Pages

Use this repository as a static Pages project:

- Build command: none
- Build output directory: `/`
